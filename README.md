# LifeRPG - 生活游戏化系统

把你的日常生活变成一场RPG冒险！记录活动获得经验值、金币、装备和称号。

## 功能特色

### 核心系统
-   **经验值系统** - 记录活动获得EXP，升级解锁新头衔
-   **金币奖励** - 完成任务赚取金币
-   **五维属性** - 力量/智力/敏捷/魅力/意志
-   **等级头衔** - 从新手冒险者到不朽传说

### 装备系统
-   **装备收集** - AI生成创意装备（普通/稀有/史诗/传说）
-   **60+种物品** - 贴近现实的物品（毛巾、瑜伽垫、蛋白粉等）
-   **使用效果** - 物品使用后获得属性加成
-   **稀有度边框** - 不同稀有度有独特的发光效果

### 任务系统
-   **每日任务** - 20+种任务，每天刷新
-   **每周任务** - 8种任务，1.5倍奖励
- ⚔️ **挑战任务** - 8种高难度任务，2倍奖励
-   **成就任务** - 8种里程碑任务

### 角色系统
-   **角色管理** - 最多创建3个角色，支持切换
-   **个人信息** - 根据身高体重学历职业计算初始属性
-   **智能属性** - AI根据具体行为判断应提升的属性

### AI系统
-  ️ **多AI支持** - 支持Ollama、OpenAI、Claude、DeepSeek
-   **AI评价** - 幽默的活动反馈
-   **智能分析** - AI自动判断活动类型和属性变化

### 现实商城系统
-   **现实奖励兑换** - 用金币兑换现实奖励（看剧、游戏、美食等30+种）
-   **习惯挑战** - 创建21天习惯挑战，每天打卡完成获得奖励
-  ️ **免罪金牌** - 购买卡牌获得特权（跳过任务、休息日、双倍奖励等）
-   **惩罚机制** - 连续7天不活跃扣除金币，保持动力

### 界面特色
-   **RPG风格** - 像素风格图标和边框
-   **等级徽章** - 根据等级显示不同颜色
-   **稀有度效果** - 装备边框发光动画

## 快速开始

### 前置要求

1. **Python 3.8+**
2. **Node.js 18+**
3. **AI服务**（任选其一）：
   - **Ollama**（本地运行，免费）
   - **OpenAI API**（需要API Key）
   - **Claude API**（需要API Key）
   - **DeepSeek API**（需要API Key）

### 安装步骤

1. 克隆或下载项目
   ```bash
   git clone https://github.com/wujy309-jpg/LifeRPG.git
   cd LifeRPG
   ```

2. 复制配置文件：
   ```bash
   copy backend\config.example.json backend\config.json
   ```

3. 运行安装脚本：
   ```bash
   install.bat
   ```

### 启动系统

**方式一：一键启动（推荐）**
```bash
start.bat
```
会同时启动后端和前端服务。

**方式二：分别启动**
```bash
# 终端1：启动后端
cd backend
python main.py

# 终端2：启动前端
cd frontend
npm run dev
```

访问 http://localhost:8000

## AI配置指南

### 方式一：使用Ollama（本地，免费）

1. 安装Ollama：
   ```bash
   # Windows
   winget install Ollama.Ollama
   
   # 或访问 https://ollama.ai 下载
   ```

2. 安装模型：
   ```bash
   ollama pull qwen2.5:7b
   ```

3. 启动系统后，在"AI 设置"中选择"Ollama (本地)"

### 方式二：使用OpenAI API

1. 获取API Key：访问 https://platform.openai.com/api-keys
2. 启动系统后，点击侧边栏的"⚙️ AI 设置"
3. 选择"OpenAI"，点击"配置"
4. 输入你的API Key和模型名称（如 `gpt-3.5-turbo`）
5. 点击"保存"并"测试"连接

### 方式三：使用Claude API

1. 获取API Key：访问 https://console.anthropic.com/
2. 在"AI 设置"中选择"Claude"
3. 输入API Key和模型名称（如 `claude-3-sonnet-20240229`）

### 方式四：使用DeepSeek API

1. 获取API Key：访问 https://platform.deepseek.com/
2. 在"AI 设置"中选择"DeepSeek"
3. 输入API Key（DeepSeek使用OpenAI兼容接口）

### 方式五：自定义AI提供商

支持任何OpenAI兼容的API接口：
1. 在"AI 设置"中选择"自定义"
2. 输入API Base URL、模型名称和API Key

| 分类 | 示例 | 金币 |
|------|------|------|
| 娱乐 | 看一集电视剧、玩游戏30分钟、看电影 | 20-80 |
| 美食 | 奶茶、大餐、甜品、网红店打卡 | 20-120 |
| 休息 | 睡懒觉、泡澡、面膜、早睡 | 15-40 |

| 购物 | 逛街、买衣服、买花 | 50-250 |

支持自定义奖励，设置你自己的兑换项目！

### 习惯挑战

投入金币创建习惯挑战，坚持打卡获得丰厚奖励：

| 挑战 | 天数 | 投入 | 奖励 |
|------|------|------|------|
| 21天早起挑战 | 21天 | 50金 | 100EXP + 50金 |
| 21天运动挑战 | 21天 | 60金 | 120EXP + 60金 |
| 21天阅读挑战 | 21天 | 40金 | 80EXP + 40金 |
| 7天断舍离 | 7天 | 30金 | 60EXP + 30金 |
| 30天存钱挑战 | 30天 | 100金 | 300EXP + 100金 |

共12种挑战模板，也可自定义创建！

### 免罪金牌

购买卡牌获得特殊权限：

| 卡牌 | 效果 | 价格 |
|------|------|------|
| 任务跳过卡 | 跳过一个不想做的任务 | 50金 |
| 休息日卡 | 允许一天不打卡不扣金币 | 80金 |
| 双倍奖励卡 | 下次任务获得双倍奖励 | 100金 |
| 惩罚护盾 | 抵挡一次金币惩罚 | 60金 |

### 惩罚机制

保持活跃，否则会扣除金币：
- 连续7天活动不足3次，扣除50金币
- 可用「惩罚护盾」抵挡一次惩罚

## 常见问题

### Q: 如何切换AI提供商？
A: 点击侧边栏的"⚙️ AI 设置"按钮，选择你想要的AI提供商，点击"配置"输入API Key，然后点击"测试"验证连接。

### Q: AI响应很慢怎么办？
A: 
- 本地Ollama：尝试使用更小的模型（如 `qwen2.5:7b`）
- 云端API：检查网络连接，或尝试其他AI提供商

### Q: 如何获取API Key？
A: 
- OpenAI: https://platform.openai.com/api-keys
- Claude: https://console.anthropic.com/
- DeepSeek: https://platform.deepseek.com/

### Q: 可以同时使用多个AI吗？
A: 目前只能同时使用一个AI提供商，但你可以随时在设置中切换。

### Q: 如何切换角色？
A: 点击侧边栏底部的"切换"按钮，打开角色管理界面，可以切换、创建或删除角色。

### Q: 任务每天都会刷新吗？
A: 是的，每日任务每天会自动刷新。每周任务每周刷新，挑战任务可重复完成。
